# Isolated dependencies for the local Qwen3-TTS voice (installed into .venv-qwen
# by setup-qwen.bat, NOT into the main app environment).

#

# PyTorch index (CUDA build when an NVIDIA GPU is present, else CPU), so they are
# intentionally not pinned here.
